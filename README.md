# psych-feedback-automation
Скрипт на Python для автоматизации обратной связи по психологическим методикам. Читает CSV с баллами испытуемых, определяет уровень по каждой шкале и создаёт отдельный текстовый файл с индивидуальной интерпретацией.

# Задача

В психологическом исследовании после сбора данных каждому испытуемому нужно отправить индивидуальную обратную связь: баллы по каждой шкале и их интерпретацию. Сложность в том, что у каждой шкалы свои числовые границы между низким, средним и высоким уровнем. Вручную это занимает часы: нужно скопировать данные в шаблон, подставить баллы, выбрать правильную интерпретацию.

# Что делает программа

- Читает CSV-файл с номерами испытуемых и баллами по шкалам
- Для каждого испытуемого определяет уровень по каждой шкале на основе заданных границ
- Создаёт отдельный текстовый файл `feedback_N.txt` с персональной обратной связью
- Обрабатывает две методики: Многомерная шкала перфекционизма Хьюита-Флита (4 шкалы) и Опросник временной перспективы Зимбардо (5 шкал)

# Стек

- Python 3
- Модуль `csv` (стандартная библиотека)
- Файловый ввод-вывод
- Циклы, условные конструкции, работа со списками

# Возможные доработки

**Улучшение кода:**
- Вынести границы уровней и тексты интерпретаций в отдельный конфиг (JSON/YAML) — чтобы добавлять новые методики без правки кода
- Разбить скрипт на функции: чтение, обработка, запись
- Добавить обработку ошибок: пустые строки, нечисловые значения, отсутствующий файл
- Экспорт обратной связи в PDF или DOCX
- Автоматическая отправка файлов испытуемым на email
