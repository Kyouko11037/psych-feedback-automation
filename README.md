# psych-feedback-automation

Скрипт на Python, который помогает готовить обратную связь для участников психологических исследований. Он читает CSV с баллами испытуемых, определяет уровень по каждой шкале и для каждого испытуемого создаёт отдельный файл с интерпретацией результатов.

**Версия 2.0**

## Задача

В психологическом исследовании после сбора данных каждому испытуемому нужно отправить индивидуальную обратную связь: баллы по каждой шкале и их интерпретацию. Сложность в том, что у каждой шкалы свои числовые границы между низким, средним и высоким уровнем. Вручную это занимает часы: нужно скопировать данные в шаблон, подставить баллы, выбрать правильную интерпретацию.

## Что делает программа

- Читает файл `points.csv` с номерами испытуемых и баллами по шкалам
- Определяет уровень (низкий, средний или высокий) по каждой шкале
- Сохраняет обратную связь для каждого испытуемого в отдельный файл в папке `results/`
- Сейчас обрабатывает две методики:
  - Многомерная шкала перфекционизма Хьюита-Флита (4 шкалы)
  - Опросник временной перспективы Зимбардо (5 шкал)

## Что нового в версии 2.0

- Первая версия была написана в Jupyter-ноутбуке, теперь это обычный скрипт `feedback_automation.py`
- Раньше для каждой шкалы был свой блок `if / elif / else`, всего девять почти одинаковых блоков. Теперь названия шкал, пороги и тексты хранятся в списке словарей `FEEDBACK_TEXT`, а уровень определяет одна функция
- Код разделён на функции
- Файлы с результатами сохраняются в папку `results/`, а не в корень проекта

## Требования

Сторонние библиотеки не нужны, используются только стандартные модули `csv` и `pathlib`.

## Как запустить

```
git clone https://github.com/Kyouko11037/psych-feedback-automation.git
cd psych-feedback-automation
python feedback_automation.py
```

Файл `points.csv` должен лежать в той же папке, что и скрипт. После запуска в консоли появится сообщение о количестве обработанных испытуемых, а файлы с обратной связью окажутся в папке `results/`.

## Входные данные

Файл `points.csv` в кодировке UTF-8. Первая строка — заголовок, дальше по одной строке на каждого испытуемого.

Данные в `points.csv` синтетические.

Важно: столбцы читаются по порядку, а не по названиям, поэтому менять их местами нельзя.

## Как определяется уровень

У каждой шкалы есть два порога. Если балл ниже нижнего порога, уровень низкий, если выше верхнего — высокий. Во всех остальных случаях, в том числе когда балл совпадает с порогом, уровень средний.

## Результат

Для каждого испытуемого создаётся файл `results/feedback_<номер>`.

## Как устроен код

- `FEEDBACK_TEXT` — описание методик. Для каждой шкалы указаны номер столбца в CSV (`column`), название (`name_of_scale`), пороги (`low_level`, `high_level`) и три текста интерпретации: для низкого, среднего и высокого уровня (`text`)
- `define_level()` — определяет уровень по баллу и порогам: 0 — низкий, 1 — средний, 2 — высокий
- `write_feedback()` — собирает текст обратной связи для одного испытуемого
- `write_in_files()` — читает `points.csv`, создаёт папку `results/` и записывает файлы

Чтобы добавить новую шкалу, нужно дописать в `FEEDBACK_TEXT` ещё один словарь с такими же ключами и добавить нужный столбец в CSV.

## Возможные доработки

- Проверка входных данных и понятные сообщения об ошибках
- Чтение столбцов CSV по названиям, а не по порядку
- Перенос описания методик в отдельный JSON-файл, чтобы добавлять новые методики без правки кода
- Экспорт обратной связи в DOCX
- Добавление других популярных у психологов методик
- Возможно: автоматическая рассылка обратной связи
